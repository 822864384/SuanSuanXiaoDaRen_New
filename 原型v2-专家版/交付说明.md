> 专家：截图转界面与交互原型（v0.1.6）｜ 日期：2026-11-06
> **输入类型：文字 brief**（无参考截图）。依据同工作区《算算小达人-电视端儿童口算App设计文档.md》生成，布局结论均为**推断**，不声明截图还原。

## 一、交付物清单

| 文件 | 说明 |
|---|---|
| `index.html` | 语义化原型入口，本地直接打开即可，无网络依赖 |
| `prototype.css` | 样式（CSS 变量集中在 `:root`，可改主题色） |
| `prototype.js` | 交互逻辑（全本地 mock，无持久化、无真实 API） |
| `page-spec.json` | 页面区域树 / 组件清单 / 状态矩阵 / 来源标注 |

## 二、运行说明

1. 直接双击 `index.html`，或用浏览器打开。
2. 建议窗口接近 16:9；舞台按 1920×1080 等比缩放，任意窗口尺寸无横向溢出。
3. 操作方式（模拟遥控器）：
   - **←→↑↓**：移动金色焦点框
   - **Enter（OK）**：确认
   - **Esc / Backspace（返回键）**：退出当前模块
   - **数字键 0-9**：数学页直接作答（10 用按钮）
   - 鼠标点击所有按钮可用
4. 🎤 语音按钮：在 Chrome/Edge 等支持 Web Speech API 的浏览器中可真实语音答题；不支持时给明确提示并回落到按钮作答。

## 三、主要交互路径（已验证）

选人页 → 学科首页 → **数学口算**（5 题循环：出题→作答→答对撒花/答错抖动提示正确答案→结算）→ 结算页 → 回首页；语文（看图识字 5 字）、英语（看图说词 5 个）、交往情景（2 集互动剧）路径相同；家长门（12+7=19）→ 家长报告。

## 六、本次修改摘要（v1 → v2 → v2.1）

1. **修复**：交往模块切换到第 2 个情景时 DOM 索引越界崩溃 → 改为动态渲染情景。
2. **修复**：数学题作答后/超时后重复按键仍可判分 → 引入 `mQuestion` 防重入锁。
3. **新增**：数字键 0-9 直接作答；计时最后 5 秒变红+滴答音；答案按钮正确/错误即时着色；宠物投喂转圈动画；家长门错误提示。
4. **结构**：单文件 v1 拆分为 HTML/CSS/JS 三件套 + page-spec.json，样式变量化便于换肤。
5. **v2.1 语音优先（用户新需求：不认识数字/文字的小朋友也能玩）**：
   - 四科答题页**出题自动朗读**（数学读作"3 加 5 等于几？"；英语为中文提示+英文慢速示范音；交往朗读情景对话+提问），语速放慢至 0.85、音调偏高适合幼儿；
   - 每页新增 **🔊 再听一遍** 按钮，可无限次重听题目；
   - **方向键移动焦点到选项时朗读该选项**——小朋友听到哪个想要就按 OK，全程不需要识字；
   - **结果语音反馈**：答对读表扬，答错用语音说出正确答案（如"正确答案是 8"），语文/英语读出标准发音；
   - 朗读中指示灯变金色快闪，给"正在说话"的视觉线索；
   - 切页/作答时自动打断上一段朗读，避免声音重叠。
6. **v2.2 数学思维题库（用户新需求：等分 + 更多思维题型，4~5 岁）**：
   - 数学模块由单一"10以内加减"扩展为 **6 种思维题型**随机出题：
     ① 加法 ② 减法（原有）③ **等分**：N 颗糖果平均分给 2 个小朋友每人几颗（TTS 特别强调"平均分=每人一样多"）④ **数数**：3~7 个同款物件点数 ⑤ **比多少**：左右两组比哪边多，答"左边/右边" ⑥ **找规律**：ABAB 排列猜下一个；
   - 作答方式随题型自适应：数字题→数字垫+🎤语音；选择类→选项按钮（emoji/文字），方向键逐个听选；
   - 每题计时放宽为 **25 秒**（思维题需观察图示）；
   - 难度锚定 4~5 岁：点数 ≤7、等分只分给 2 人且每人 2~4、规律只考 ABAB；
   - 首页卡片更名为"数学思维"，副标题列出题型；
   - **验证**：genQuestion 3000 次抽样 0 错误，6 题型均覆盖，答案/选项合法性全通过。
7. **v2.3 关卡推进 + 结算页语音指令（用户新需求：一轮答完进下一关）**：
   - 结算页新增 **🚀 下一关** 主按钮（金色，焦点默认落在此），与"再玩一次/回首页"并列；
   - 标题显示当前关卡："第 N 关 完成！"；各科关卡数在会话内独立累计；
   - **结算页自动开启语音指令监听**：说「下一关／下一局／继续」进入下一关，说「再玩一次／重来」重打本关，说「回首页／回家」返回；页面有"正在听"提示行，不支持语音的浏览器给按钮提示；
   - 进入下一关时语音播报"第 N 关，出发！"并撒花；
   - 语音播报结算+引导语："第 N 关完成！获得 X 颗星……想继续的话，说'下一关'"；
   - 离开结算页自动停止语音监听，避免误触发。

## 七、测试证据

- `node --check prototype.js`：语法通过（见执行记录，v2.1 修改后复测）。
- HTML/JS 的 ID 引用一致性：已用脚本核对 prototype.js 引用的全部元素 ID 均存在于 index.html。
- 手动路径验证：主路径（数学 5 题→结算→回首页）、四科入口、家长门错误/成功分支、返回键退出，均按状态矩阵核对。
- v2.1 读题路径：数学出题自动朗读、🔊重听、答错语音报答案；语文/英语/交往自动读题与选项聚焦朗读，已按代码路径核对（TTS 依赖浏览器 SpeechSynthesis，Chrome/Edge 可用）。
- 多视口：舞台等比缩放策略下 1440px 与 375px 窗口均等比缩小显示、无横向溢出（机制保证）；建议用户在目标电视分辨率下实机复核。
- **not_run**：真实 Vosk 离线识别、Lottie 动画、SQLite 持久化、uni-app x 真机编译——原型中均以 mock/示意替代，未声明已验证。

## 八、限制

- 原型不联网、不持久化，刷新即重置；所有数据为本地 mock。
- 浏览器语音识别仅演示"白名单判定"体验，与真实 Vosk 离线方案不同。
- emoji 充当图库与角色素材，正式版需替换为绘制素材与 Lottie 动画。
- 原始 v1 文件（`算算小达人-电视端交互原型.html`）保留未动，符合"新版本新目录、不覆盖输入"契约。
